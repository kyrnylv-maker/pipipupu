## Быстрый старт

### Вариант 1: Напрямую открыть файл
```bash
# Просто откройте файл в браузере
open index.html
# или
open dist/index.html
```

### Вариант 2: Локальный сервер (рекомендуется)
```bash
# С помощью Python
python3 -m http.server 8000

# С помощью Node.js
npx serve .

# С помощью PHP
php -S localhost:8000
```

Затем откройте: http://localhost:8000

## 🧪 Тестирование

### Mock режим (без реального бэкенда)

Если бэкенд недоступен, используйте mock режим:

```javascript
// Откройте консоль браузера (F12) и выполните:
localStorage.setItem('mockMode', 'true');
location.reload();
```

### Тестовые данные для входа

В mock режиме используйте любые данные:
- **Логин**: test
- **Пароль**: test

Без mock режима используйте реальные данные с вашего бэкенда.

## 🐛 Решение проблем

### Ошибка CORS
Если видите ошибку CORS:
1. Используйте локальный сервер (не открывайте файл напрямую)
2. Убедитесь, что бэкенд настроен для CORS

### WebSocket не подключается
1. Проверьте, что используете WSS (не WS) для HTTPS
2. Проверьте токен авторизации
3. Используйте mock режим для тестирования

### Ничего не отображается
1. Откройте консоль (F12)
2. Проверьте наличие ошибок
3. Очистите localStorage:
```javascript
localStorage.clear();
location.reload();
```

## 📱 Использование

### Первый запуск

1. Откройте приложение
2. Нажмите "Регистрация"
3. Введите:
   - Имя
   - Логин
   - Пароль
4. Нажмите "Зарегистрироваться"

### Отправка сообщения

1. Выберите чат из списка (если есть)
2. Введите текст в поле ввода
3. Нажмите Enter или кнопку отправки

### Переключение темы

Нажмите на иконку солнца/луны в правом верхнем углу
