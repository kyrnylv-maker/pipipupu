# 🚀 Быстрый старт

## Запуск приложения

1. Откройте `index.html` в браузере
2. Или используйте локальный сервер:
   ```bash
   npx serve .
   ```

## Тестовый режим (Mock Mode)

Для тестирования без подключения к реальному бэкенду:

1. Откройте консоль браузера (F12)
2. Выполните:
   ```javascript
   localStorage.setItem('mockMode', 'true');
   location.reload();
   ```

Тестовые данные:
- **Логин**: john_doe
- **Пароль**: любой (в режиме mock)

## API Endpoints

**Base URL**: `https://pipipupu-production.up.railway.app`

### Авторизация
- `POST /api/auth/register` - Регистрация
- `POST /api/auth/login` - Вход

### Чаты
- `GET /api/chats` - Список чатов
- `GET /api/chats/:id/messages` - Сообщения чата
- `POST /api/chats/:id/messages` - Отправить сообщение

### Каналы
- `GET /api/channels` - Список каналов
- `POST /api/channels` - Создать канал
- `POST /api/channels/:id/subscribe` - Подписаться

## WebSocket

**URL**: `wss://pipipupu-production.up.railway.app?token={TOKEN}`

### События
- `message` - Новое сообщение
- `typing` - Набор текста
- `reaction` - Реакция на сообщение
- `user_online` - Пользователь онлайн
- `user_offline` - Пользователь офлайн

## Отладка

Включить подробное логирование:
```javascript
localStorage.setItem('debug', 'true');
```

Очистить все данные:
```javascript
localStorage.clear();
location.reload();
```

## Troubleshooting

### WebSocket не подключается
- Проверьте токен авторизации
- Проверьте доступность бэкенда
- Откройте консоль для деталей ошибки

### Сообщения не отправляются
- Убедитесь, что WebSocket подключен
- Проверьте, что чат выбран
- Проверьте лимит длины сообщения (4096 символов)

### Темная тема не работает
- Очистите кэш браузера
- Проверьте localStorage
